MEGURU SESSION — Resume from here
==================================

## What is Meguru

Client-side browser app for seasonal stock trading analysis of Indian (NSE) stocks.
Vite 6 + Preact (class components only, no hooks), Chart.js, C++ WASM engine,
Yahoo Finance data via Cloudflare Worker CORS proxy.
Two sub-projects: engine/ (C++) and web/ (JS).

## Architecture: JS-feeds-CSV (FINAL)

JS reads CSV strings from OPFS via File System Access API (storage.js),
passes each to _module.loadCsv(symbol, year, csvString),
then calls _module.compute(symbol, params).
No WasmFS, no pthreads, no JSPI. All C++ calls synchronous.
engine.addStock() in engine.js is async (OPFS reads async).

## WASM Build

Flags: --bind, -sMODULARIZE=1, -sEXPORT_ES6=1, -sEXPORT_NAME=createEngine,
-sALLOW_MEMORY_GROWTH=1, -sENVIRONMENT=web, -sASSERTIONS=2, --no-entry.
MEGURU_DEBUG=ON (DEBUG_LOG macro → printf → console.log).

Build commands:
  cd engine/build_wasm && rm -rf *
  export PATH="/usr/lib/emscripten:$PATH"
  emcmake cmake .. -DCMAKE_BUILD_TYPE=Release -DMEGURU_DEBUG=ON
  emmake make -j$(nproc)
  cp meguru.js meguru.wasm ../../web/public/wasm/

Emscripten: /usr/lib/emscripten/ (pacman, v5.0.5)
Artifacts: web/public/wasm/meguru.js (~115K) + meguru.wasm (~210K)
Blob URL trick: Vite 6 blocks import() of JS from public/. engine.js fetches
meguru.js as text → blob URL → import(). locateFile callback for .wasm path.

## Bugs Fixed This Session

1. valarray brace-init: TPrices{0.0, DAYS} → initializer_list (2-elem), not
   valarray(0.0, DAYS) (366 zeros). Heap corruption → crash in free() after
   loadCsv. Fixed in types.h:91, basket.h:10, basket.cpp:226,236.

2. App.jsx sync→async: _restoreState and handleFetchComplete were calling
   engine.addStock() synchronously (leftover from WasmFS approach). Now async/await.

3. Modal layout jump: dropdown open/close + error message toggle changed modal
   height → re-centered → visible jump. Fixed:
   - Error messages use visibility:hidden/visible (always reserve space)
   - Stock error only shown after Add clicked (bAttempted flag)
   - Modal overlay back to align-items:center (height now stable)

## C++ Style Rules

Hungarian: n=count, i=index, f=float, pct=percent, s=string, b=bool, arr=array, map=map, m_=member
Prefixes: T=type, C=class, I=interface, E=enum
Aliases: str, cstr, sv, vstr, vint, vf64, i32, i64, u64, f64
TPrices=valarray<f64>, TDayIndices=vint
C++23, #pragma once, using namespace std
std::sort not std::ranges::sort, std::move() not move()
CREF(T), CAUTOREF, CAUTO, FOR, FORLE, DEBUG_LOG macros
See CPP_STYLE.md
